# 《MooMoo 的东岸小假期》v1

原创合成器试听版，2026-11-01。不是实录钢琴/单簧管，也未使用外部歌曲、录音采样或远程音乐服务。

- 88 BPM，F 大调，4/4，44 小节，120 秒，轻微摇摆八分音符。
- 4 小节开场 → 8 小节主题 → 8 小节变化 → 8 小节桥段 → 8 小节主题回归 → 8 小节收尾。
- 合成钢琴主旋律，拨弦木吉他和低音伴奏，柔和刷鼓，部分段落用簧管类音色，少量颤音琴点缀。
- 母带：32 kHz、16 bit、双声道 WAV；运行版 AAC/MP4 放入美东地图内容包。
- 固定随机种子，仅用于微小力度/时间变化和打击乐噪声；所有有音高音符记录在 `score.json`。
- 尾音和短混响按整曲周期回绕；母带峰值 0.72、RMS 约 0.099，无削波。环接样本差小于 0.001；浏览器压缩音频环接体验仍需听感反馈。

复现命令（需 numpy，游戏本身不依赖 Python）：

```sh
uv run --no-project --with numpy python scripts/compose-east-coast.py
```

脚本拒绝覆盖已有母带；再次编曲先另建版本路径。`previous-music.js` 保存接入前的播放器代码供对照。

游戏中 `mapPack.music` 可选字段包含 `src/title/description/durationSeconds`；未配置时使用原日本曲目。地图更新/预览切换时跟随主题，只有已由用户开始的播放会继续；新的访问默认暂停等待点击。音量沿用原独立 localStorage 偏好，不改变对局状态。

验证记录：AAC 文件由系统音频工具确认 120 秒、32 kHz 双声道；浏览器确认美东音频播放进度正常递增、2:00 时长、循环属性、暂停、主题切换、音量保存和刷新后等待点击，控制台无错误。53 项现有测试及四张旧原图校验通过。默认本体静态导出 3,077,654 字节，仍在 3 MiB 内（不含可选地图和本次配乐）。没有修改规则/计分文件，未发布。
