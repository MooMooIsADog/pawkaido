# 汪汪东海道 · Pawkaido

带着 MooMoo、Yuki（哈士奇）、Biscuit（柯基）和 Rex（德牧），一起吃饭、看风景、泡汤、收集旅途的小宝贝。

Pawkaido 是以《东海道》标准版四人规则为基础的狗狗主题浏览器游戏。你可以在日本浮世绘或美国东海岸复古卡通地图上旅行，选择经典玩法，或加上每只狗狗的专属心愿。游戏在本地运行，无需账号，没有在线服务、外部字体或远程 AI。

## 开始游戏

推荐使用 Node.js 24；项目的 `.nvmrc` 已指定该版本。使用 nvm 时，首次在项目目录运行 `nvm install`，之后运行 `nvm use`。

```sh
cd pawkaido
npm start
```

打开 [本地游戏](http://127.0.0.1:4175/)。只依赖 Node.js，无需 `npm install`。端口可用 `PORT=4177 npm start` 修改，服务只监听本机。`package.json` 中的 `private` 只是防止误发布 npm 包，不是登录或访问限制。

开局可以选择：

| 选项 | 可选内容 |
| --- | --- |
| 操作方式 | 单人：你控制 MooMoo，另外三只由本地 AI 控制；四人同屏：轮流操作四只狗狗 |
| 游戏规则 | 经典版，或增加专属心愿的狗狗能力扩展版 |
| 旅行地图 | 日本 · 东海道，或美国 · 东海岸漫游 |

**地图与玩法独立组合。** 两套地图都支持经典版和心愿扩展，地图改变风景、主题名称与配乐，不改变地点顺序、奖励、计分或 AI 规则。

## 怎么玩

旅行的目标是收集最多的旅途分数。走得最快不一定获胜，沿途停在哪里、留多少饭钱、收集哪些风景，才是每一步要考虑的事。

1. **选旅行能力。** 每只狗从随机发到的两张能力牌中选一张；共有十种能力，起始盘缠随能力变化，四只狗都能抽到任意能力。
2. **最靠后的狗先行动。** 不投骰子，直接选择前方有空位的合法地点；只能前进，跳过的地点不会触发事件，也不能回头补停。同一地点有两只狗时，外侧的狗先行动。
3. **停下来收集回忆。** 点击路标查看地点详情，再点“带我去这里”。狗狗会沿小路走过去，到站后在棋盘中央弹窗中完成选择。
4. **驿站一起开饭。** 四座驿站必须停靠，含最终目的地。先到的狗先从共享菜单选饭，每站最多一份，同一种鲜食整趟旅程只能吃一次。大家到齐并完成用餐选择后，才进入下一段；最后到的狗先出发。
5. **终点结算。** 全员到达并完成最后一次用餐选择后，加上成就与捐赠排名奖励，总分最高者获胜。同分时比较成就卡数量，仍相同则共享胜利；剩余金币不换分。

沿途地点会提供不同的机会，以下使用日本地图的名称；美东地图会换成当地主题文案，效果相同。

| 地点 | 可以做什么 |
| --- | --- |
| 农庄 | 帮忙赚取金币，为吃饭、购物和捐赠准备盘缠 |
| 风景 | 收集稻田、山景、海景画卷；分别需要 3、4、5 片，每幅越往后收集，单片分数越高 |
| 小铺 | 购买伴手礼，按不同类别组套得分 |
| 汤屋 | 抽取泡汤卡，获得卡面分数 |
| 相遇 | 结识朋友，获得金币、礼物、风景或其他奖励 |
| 神社 | 捐赠金币获得分数，并参与终局捐赠排名 |
| 驿站 | 从共享菜单选择鲜食，每份 6 分；也可以选择不吃 |

游戏内的规则说明由 MooMoo 用第一人称讲解。终局排行榜可展开每只狗狗的得分分解，先展示获得的成就，再查看心愿奖励和各项分数来源。

三位 AI 与玩家使用同一规则引擎，根据公开信息估算收益、前进距离并预留饭钱；只处理已经翻给自己的牌，不偷看牌堆，也没有额外资源。本项目采用标准版四人对局，不采用新版实体单人规则。

### 狗狗心愿扩展

经典版保留十种旅行能力；狗狗能力扩展版在此基础上，为四只狗各增加一个固定心愿。完成时立即加分，每局只奖励一次。

| 狗狗 | 心愿 | 完成条件 | 奖励 |
| --- | --- | --- | --- |
| MooMoo | 大馋丫头 | 三个中途驿站每站都吃一份鲜食 | +6 分 |
| Yuki | 好奇探险家 | 集齐三幅画卷：稻田 3 片、山景 4 片、海景 5 片 | +6 分 |
| Biscuit | 泡汤小享受家 | 在三座不同汤屋成功泡汤 | +6 分 |
| Rex | 勤劳小帮手 | 在两座不同农庄帮忙 | +4 分 |

免费餐计入 MooMoo 的心愿，终点那顿不能补中途缺餐。Yuki 收到的相遇赠送、旅行能力奖励和开局赠送画卷也计入进度。心愿分独立记账，不增加成就卡数量，也不触发成就卡相关的能力加分。

旧存档继续使用当局记录的心愿条件和奖励，不会因为版本更新而改变已经开始的对局。

## 两套地图，八幅风景

每套地图都有四章，随旅行进度切换。日本地图采用浮世绘画风，美东地图采用美式复古卡通画风；它们共用同一套 55 个位置和四阶段规则。

| 章节 | 日本 · 东海道 | 美国 · 东海岸漫游 |
| --- | --- | --- |
| 第一章 | **京都 · 近江**：樱桥、琵琶湖与铃鹿山麓 | **波士顿 → 纽波特**：金顶、普罗维登斯河岸与破碎者大宅 |
| 第二章 | **伊势 · 三河**：伊势湾、帆影与三河海岸 | **纽波特 → 纽约**：港湾、Mystic、纽黑文与纽约天际线 |
| 第三章 | **骏河 · 富士**：富士山雪顶与骏河湾 | **纽约 → 费城**：果园、运河、普林斯顿与费城地标 |
| 第四章 | **箱根 · 江户**：芦之湖、青山与终点灯火 | **费城 → 华盛顿**：巴尔的摩内港、安纳波利斯与首都纪念建筑 |

想看完整的插画和卡面故事，可以翻开[《汪汪东海岸 · MooMoo 的美国旅行手账》](docs/east-coast.md)。

美东路线沿弯曲小路从右上向左下前进，绕过城市和田野。第一章的普罗维登斯藏着卡通化的 Lovecraft 肖像；第四章从巴尔的摩前往华盛顿的路上，有爱伦·坡、黑猫和乌鸦组成的文学彩蛋。

地图工具栏的 **「MooMoo 讲风景」** 会介绍当前这幅地图的代表景物和旅程含义；**「全程路书」** 可以预览四章路线，并分别打开风景介绍。阅读时暂停 AI，关闭后继续旅行。

这些地图是为游戏绘制的艺术化旅行手账，地理距离、方位和地点间距经过调整，不能用于现实导航。爱伦·坡与动物的组合小景也是插画设定，并非现实路边雕像的记录。

### 随地图切换的音乐

| 地图 | 默认配乐 | 风格 |
| --- | --- | --- |
| 日本 · 东海道 | 《樱风里的小爪印》 | 和风五声音阶，筝风格拨弦、笛声与轻木敲音；64 BPM，60 秒循环 |
| 美国 · 东海岸漫游 | 《MooMoo 的东岸小假期》 | 复古轻爵士，钢琴、木吉他、低音、簧管、颤音琴与柔和刷鼓；88 BPM，120 秒循环 |

两首曲子均为本项目原创合成音乐，在本地循环播放。音乐默认开启；如果浏览器拦截自动播放，第一次点击游戏后开始。音乐条提供开关和音量调节，关闭偏好与音量会保存，换地图后也会保留。

## 操作与存档

- 地图按浏览器窗口缩放；可用“放大地图”查看细节、“定位狗狗”找到当前角色，或切到“地点列表”查看地点卡片。
- 狗狗沿道路移动，抵达后显示事件；系统开启减少动态效果时直接显示到站事件。
- 点击角色头像查看旅行能力、收藏、心愿进度和账本。
- 本地自动存档保存当前事件、牌堆和地图选择。刷新不会重新抽牌；行走中刷新也不会重复获得奖励。
- 旧存档默认使用日本地图。缺少地图包时以日本地图显示原进度；缺少当前对局所需的玩法扩展时，会提示恢复对应扩展。

## 内容包与开发

玩法扩展与地图内容包分别管理，当前均为本地安装机制，没有自动下载或在线更新服务。

| 内容 | 目录或说明 |
| --- | --- |
| 狗狗心愿：规则、AI 偏好、存档校验与展示 | `dist/extensions/dog-wishes/` · [扩展开发说明](docs/extensions.md) |
| 日本地图 | `dist/map-packs/japan/` |
| 美东地图、主题文案与配乐 | `dist/map-packs/east-coast/` · [地图内容包说明](docs/map-packs.md) |
| 地图制作 skill | [.agents/skills/pawkaido-travel-maps/SKILL.md](.agents/skills/pawkaido-travel-maps/SKILL.md) |

美东四张最初原图永久保存在 `artifacts/east-coast-maps-v1/`，弯道修订版保存在 `artifacts/east-coast-maps-v2/`；运行时使用独立 WebP 副本。原图设为只读并有哈希校验，将来修图应另建版本目录，不覆盖这些原图。

日本地图使用 `dist/assets/ukiyo-map-atlas.png` 四宫格图集，提示词保存在 `artifacts/ukiyo-map-prompt.txt`。四只狗狗复用 Moonopoly 精灵图和帧表；未修改旧游戏，也未使用原桌游图像或抄录规则书文案。

和风配乐生成脚本为 `scripts/compose-music.py`。美东配乐生成脚本为 `scripts/compose-east-coast.py`，母带、乐谱事件及说明保存在 `artifacts/east-coast-music-v1/`；生成时需要 NumPy，游戏运行无需安装它。

### 添加自己的旅行路线

仓库附带的 **pawkaido-travel-maps skill** 覆盖路线与地标规划、绘图与修图、原图保护、弯道标定、主题接入和浏览器验收，并提供路线坐标编译器、原图哈希与只读校验器。

在支持项目 skills 的助手中，可以这样提出任务：

```text
使用 $pawkaido-travel-maps，帮我增加一套意大利旅行地图内容包。
保持现有规则和四只狗不变；先规划四章路线与地标，画风用复古明信片风，先画第一章让我看。
```

如果客户端没有自动发现 skill，让助手先读取 `.agents/skills/pawkaido-travel-maps/SKILL.md`。skill 随仓库保存，无需复制个人配置或凭据；绘图需要助手环境中可用的图像生成工具。

## 验证

```sh
npm test
node scripts/check-map-originals.mjs
```

测试覆盖行动合法性、全部十种旅行能力、牌库与分数账目、存档恢复、成就与并列结算、心愿扩展兼容、地图资源与路线一致性、不同地图下同种子对局一致性，以及音乐默认播放和关闭偏好。原图检查单独核对四张最初地图的哈希与只读状态。

平衡性模拟可运行 `npm run balance -- 1000`，比较两种选能力策略下各 1,000 对经典/扩展对局；`npm run balance -- 1000 unaware` 使用不主动追求心愿的 AI。模拟结果是特定 AI 策略下的表现，不代表真人胜率。

玩法与交互验证见 [QA.md](QA.md)，地图验收见 [地图内容包验证记录](docs/map-packs-qa.md)。
